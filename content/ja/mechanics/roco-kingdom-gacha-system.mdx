### 「ゼロ・ペイウォール」があなたにとっておそらく意味すること

「ゼロ・ペイウォール」は「ゼロ・マネタイズ」ではない。実際には、無料プレイのクリーチャーコレクターは通常3つをマネタイズする。利便性、コスメティック、ランダム報酬だ。最初の2つは無害だ。3つ目が支出規律の重要なところだ。このフレーズは*コンテンツアクセス*に関する約束、つまりストーリーを続けるために支払いを要求する閉ざされた扉にぶつからないという約束として扱い、すべてのJiniスキンが無料になるという約束とは考えないことだ。

## クリーチャーコレクターにおけるガチャメカニクスの通常の仕組み

無料プレイのコレクターゲームを遊んだことがあるなら、用語は馴染み深いだろう。以下の表は、ローンチ日のあらゆる議論スレッドで目にする用語を定義しており、パッチノートやコミュニティガイドを推測なしで読めるようにする。

| 用語 | 意味 | ここで重要な理由 |
| --- | --- | --- |
| **バナー** | 期間限定の特典報酬プール | お気に入りのJini外見が*今*入手可能かを決める |
| **引き / ロール** | プールへの有料または無料の1回の試行 | 支出の基本単位。通常は割引バンドルで販売 |
| **排出率** | 各レアリティ層の公表確率 | 常に公開されるが、時には埋もれる。支出前に見つけること |
| **天井** | 設定回数の引き後の保証報酬 | 安全網。カウンターがどこにあるか知らずに支出しないこと |
| **ソフト天井** | 保証に近づくにつれて上昇する確率 | 賢い支出家が引きを集中させる場所であることが多い |
| **ピックアップ** | 確率が上がった特典アイテム | 50%と0.7%の確率の差は甚大 |
| **被り** | すでに所持しているものの重複 | 重複が有用な通貨に変換されるかを決める |
| **スパーク / 交換** | 天井トークンでアイテムを直接購入できるショップ | 運の悪いプレイヤーにとって最も信頼できる道 |
| **分割通貨** | 混ぜられない無料通貨と有料通貨 | 無料通貨は通常プレミアムバナーを購入できない |

実践的な要点：これらのシステムを持つあらゆるゲームで、**天井カウンターは運よりも価値がある**。それを一貫して追跡するプレイヤーは、新しいバナーごとに衝動的に引くプレイヤーよりもはるかに少ない支出で欲しいアイテムを手に入れる。

## コミュニティ報告とローンチ前に監視すべき危険信号

ジャンルからのプレイヤー経験、そしてRoco Kingdomのテスト募集に関する初期の議論は、ゲームがライブになったら監視する価値のあるいくつかの警告サインを指摘している。これらはいずれも確認された問題ではない。健全なシステムと搾取的なシステムを分けるものだ。

- **隠された、または曖昧な排出率。** いくつかの市場の規制当局は開示を要求している。排出率が公表されないなら、危険信号として扱う。
- **見えない天井カウンター。** 追跡できない保証は保証ではない。
- **見た目が同じで結合できない無料通貨と有料通貨** — 偶発的な支出の古典的な原因。
- **すべてのバナーにFOMOタイマー。** 絶え間ない限定ウィンドウが衝動買いを促す。
- **重複に結びついたパワー。** 重複Jiniが戦闘力を意味的に強化するなら、コスメティック第一の約束は破られる。

1つの安心材料：ゲームはEasy Anti-Cheatを使用し、アカウント紐付けクライアントを要求する。これは少なくとも、購入が使い捨てのゲストログインではなく、安全なプロフィールに紐付けられることを意味する。ローンチ時にMorefun Studiosが使用するアカウントシステムでは、二要素認証をオンにしておくこと。
