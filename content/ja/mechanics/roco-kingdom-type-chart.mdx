## ロコキングダム タイプ相性表が実際に果たす役割

根本的に、この相性表はグリッドです。攻撃側が左側の行に並び、防御側が上部の列に並び、各セルには3つの結果のいずれかが入ります。RocoDexの参照マトリクスではシンプルな凡例が使われています：**2×**は効果バツグン、**½×**は効果イマイチ、ダッシュは標準的な補正なしのヒットです。

| 相性表の結果 | ラベル | バトルでの意味 |
|---|---|---|
| 2× | 効果バツグン | ダメージが2倍になる — 攻撃のゴーサイン |
| –（ダッシュ） | 等倍 | 標準ダメージ、ボーナスもペナルティもなし |
| ½× | 効果イマイチ | ダメージが半分になる — 通常は交代の合図 |

ここで注目すべき点が2つあります。第一に、凡例には3つの結果しか記載されていないため、他のモンスターバトルゲームのように「耐性」のある相性がすべて完全無効化になるとは考えないでください。第二に、グリッドのサイズは対称なので、防御タイプが18種類ある相性表は18行×18列、つまり最大324個のセルを確認する可能性があるということです。

恐ろしく聞こえますが、そうではありません。324個すべてを一度に必要とすることは決してないからです。目の前の戦闘に必要なのは、1つの行と1つの列だけです。

## マトリクスを行ごとに読む

相性表を学ぶ最速の方法は、攻撃側の行を1つずつ読むことです。公開されているRocoDexマトリクスから、2つの完全な行をそのまま転記するとこうなります。

**ノーマルを攻撃タイプとする場合：**

| 攻撃側 | 防御側 | 結果 |
|---|---|---|
| ノーマル | じめん | ½× |
| ノーマル | ゴースト | ½× |
| ノーマル | メカ | ½× |
| ノーマル | 他の15タイプすべて | 等倍（–） |

**くさを攻撃タイプとする場合：**

| 攻撃側 | 防御側 | 結果 |
|---|---|---|
| くさ | ほのお | ½× |
| くさ | ドラゴン | ½× |
| くさ | どく | ½× |
| くさ | むし | ½× |
| くさ | ひこう | ½× |
| くさ | メカ | ½× |
| くさ | みず | 2× |
| くさ | ひかり | 2× |
| くさ | じめん | 2× |
| くさ | 他の9タイプすべて | 等倍（–） |

パターンに気づいたでしょうか：ほとんどのセルは等倍です。典型的な行には2×と½×の項目がほんの少ししかありません。これは朗報です — 空白を除いてしまえば、1行を覚えるのに30秒ほどしかかからないということです。

相性表を防御的に使うには、プロセスを逆にします。ほのおのクリーチャーと対面しているなら、行ではなくほのおの**列**をスキャンして、自分の攻撃タイプのどれが½×に軽減されるかを確認し、それらの技は完全に避けましょう。

## 複合タイプと倍率の重ね掛け

ロコキングダムのほとんどのクリーチャーは2つのタイプを持っており、RocoDexの計算ツールは明示的に「最大2タイプを選択（複合タイプ防御）」を可能にしています。つまり最終的な倍率は、単一の参照ではなく2つの別々の相性表参照の組み合わせになります。

コミュニティのプレイヤーによると、計算ツールは両方の防御結果を掛け合わせるため、単一タイプの相性では決して起こらないほど多様な結果が生まれます：

| 1回目の参照 | 2回目の参照 | 組み合わせ結果 |
|---|---|---|
| 2× | 2× | 4× — 壊滅的 |
| 2× | ½× | 1× — 相殺 |
| 2× | – | 2× |
| ½× | ½× | ¼× — ほぼ壁 |
| ½× | – | ½× |
| – | – | 1× |

これがバトルにおける悪い判断の最も一般的な原因です。プレイヤーは「ほのおはくさに強い」と見て、くさ/みずのクリーチャーに技を放ち、みずの半分が結果を引き下げてしまうことに気づきません。大きな攻撃を仕掛ける前に、必ず複合タイプの両方の半分を確認しましょう。

## 30秒以内にあらゆる相性を確認する方法

暗記よりもスピードが重要です。RocoDexのタイプ計算ツールの構成を参考にした、次のルーティンを使いましょう：

| ステップ | アクション | 重要な理由 |
|---|---|---|
| 1 | 防御側の完全なタイプを特定する | 複合タイプはすべてを変える |
| 2 | タイプ計算ツールを開く | 記憶より速くて安全 |
| 3 | 自分の攻撃タイプを入力する | 入力1つ、答え1つ |
| 4 | 防御側の両方のタイプを入力する | 2つ目のタイプが忘れられがち |
| 5 | 組み合わせ倍率を読む | 攻撃前に2×以上を探す |
| 6 | 逆方向の相性を確認する | 防御側が自分に何をできるか確認する |

ステップ6は初心者が飛ばしがちなものです。自分の技が効果バツグンであることを知るのは話の半分にすぎません — 防御側のタイプ一致技も自分の場のクリーチャーに対して効果バツグンなら、ダメージレースに勝っても交換で負ける可能性があります。

## 相性表を網羅するチームの構築

ロコキングダムのタイプ相性表に基づいて構築されたチームは、最強のクリーチャーを積み上げることではありません。単一の対戦相手タイプに全滅させられないようにすることです。

ロスターを見直す際は、このチェックリストを使ってください：

- **攻撃タイプを数える。** 6体のうち3体が同じ攻撃タイプを共有しているなら、見た目よりカバレッジは薄いです。
- **防御の穴を確認する。** どのタイプが自分の2体以上に2×で当たるかを特定し、それが許容できるか判断しましょう。
- **よくあるタイプへの答えを少なくとも1つ持つ。** くさ、ほのお、みずはプレイヤー体験の報告で常に登場するため、この3つすべてへの対策はほぼ必須です。
- **共通の弱点を重複させない。** 同じ搾取可能な弱点を持つ2体は、対戦相手のカバレッジ技1つで除去されかねません。
- **等倍アタッカーを1体キープする。** ほとんどが等倍の相性を持つクリーチャーは、相性表が不明瞭なときの安全な交代先になります。

| カバレッジ目標 | 健全な兆候 | 警告サイン |
|---|---|---|
| 攻撃の広がり | 4種類以上の異なる攻撃タイプ | 2〜3タイプしかいない |
| 防御の安全性 | 自分のチーム3体以上に2×で当たるタイプがない | 1つのタイプがロスターの半分を脅かす |
| 交代の選択肢 | 主要な弱点に耐性を持つクリーチャーが2体以上 | 最悪の相性に対する安全な交代先がゼロ |
| スピード管理 | 高速アタッカーが少なくとも1体 | チーム全体が遅く受け身 |

## プレイヤーが相性表で犯しがちなミス

- **どこにでも無効化があると思い込む。** 公開されている凡例には2×、½×、等倍しか記載されていません。確認していない限り、ゼロダメージの壁を前提に計画しないでください。
- **2つ目のタイプを無視する。** 複合タイプの防御側は例外ではなく標準です。
- **グリッド全体を暗記しようとする。** 実際に使うタイプの行だけを覚え、残りは調べましょう。
- **相性表をダメージ計算機として扱う。** これはダメージを補正するものであり、ステータス、レベル、スキル威力は考慮しません。
- **逆方向の相性を忘れる。** 効果的な攻撃は有利な交換を保証しません。

## FAQ

**ロコキングダムのタイプ相性表は他のモンスターバトルゲームと同じですか？**
いいえ。18タイプを使用していますが、いくつか — ひかり、キュート、メカ — は他に対応するものがなく、公開されている凡例には2×、½×、等倍の結果しか記載されていません。ロコキングダムのタイプ相性表は、他のゲームから翻訳するのではなく、独自のシステムとして扱いましょう。

**ロコキングダムのタイプ相性表では複合タイプの防御側はどう機能しますか？**
攻撃側を防御側の2つのタイプそれぞれに対して個別に参照し、その結果を組み合わせます。コミュニティの報告によると、2つの倍率は掛け合わされ、4×という高い結果や¼×という低い結果を生み出すことがあります。

**324個のセルすべてを暗記する必要がありますか？**
いいえ。ほとんどの行には等倍以外の項目が少ししかありません。実際にバトルで使うタイプの行を覚え、それ以外は計算ツールをブックマークしておきましょう。

**攻撃前に確認すべき最重要事項は何ですか？**
防御側の完全なタイプです。コストの高いミスプレイのほとんどは、複合タイプの片方だけを確認して結果が変わらないと仮定することから生じます。

相性表をルーティンに取り入れれば、それはもう宿題ではありません。相性を確認し、逆方向も確かめ、数字に交代を決めさせましょう。
